# pi-remote Logo

标志将圆润的 π 与独立连接端点结合，表达从移动设备连接本地 pi 编程助手。主色沿用 iOS 项目的深绿 `#216B52`，浅色为 `#F7F8F5`，字标为 `#202522`。

[Figma 可编辑源文件](https://www.figma.com/design/MYzy83BB74HsCJXVsm7PIZ)

- `pi-remote-mark.svg` / `.png`：透明背景独立标志，PNG 为 1024 × 1024。
- `pi-remote-logo.svg` / `.png`：透明背景横版字标，用于浅色背景；SVG 文字已转轮廓，不依赖字体安装。
- `pi-remote-app-icon.svg` / `.png`：深绿底应用图标，PNG 为 1024 × 1024；保留方形底，由平台裁切圆角。
- `pi-remote-preview.png`：展示图，含圆角图标和字标。

使用时保持比例和留白，不拉伸、不移动独立圆点。已检查 Figma 导出效果和 64 px 图标预览。当前交付为设计资源，尚未替换 iOS 工程中的应用图标。
